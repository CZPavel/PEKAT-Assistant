# Security

Do not post credentials, license material, customer images, production archives, private addresses or installation binaries in public issues. Use minimal synthetic examples and redact identifiers from logs.

Treat uploaded projects and Code as untrusted evidence. Do not execute supplied Code, deserialize unsafe formats or load unknown model weights merely to explain a project.

For a suspected disclosure, use an available private repository security reporting channel. If none exists, request a private contact without posting sensitive details.

This preview provides advisory content and packaging tools, not a PEKAT or hardware control interface.
