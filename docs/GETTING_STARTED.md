# Getting started

Read the [knowledge index](../knowledge/INDEX.md). Supply a sanitized inspection objective, exact PEKAT version, available evidence and measurable acceptance criterion.

Copy the complete `.github/skills/pekat-assistant` folder, including generated `references`, into your Codex skills directory. Keep the folder name `pekat-assistant`. Invoke `$pekat-assistant` or use normal automatic discovery. Installation does not connect to PEKAT or equipment.

For a Custom GPT follow [GPT setup](../gpt/README.md). Review data handling before uploading project information.

Try: “Explain this sanitized FLOW description and identify conclusions that require evaluated results.” See the [example](../examples/advisory-workflow.md).
