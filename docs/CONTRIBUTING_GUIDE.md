# Contributing guide

Describe the user problem, exact scope, evidence type and limitation. Prefer an original explanation to reproduced vendor text. Public official links must support the actual claim.

Use synthetic examples without private identities, paths, addresses, payloads or schemas. Keep documentation, static evidence and executed validation separate. A native resource or feature does not make an assistant workflow available.

Preserve scenario status and preview advisory boundaries. Regenerate packages and run the commands in [Publication model](PUBLICATION_MODEL.md). Report checks actually performed and remaining runtime/hardware gaps.
